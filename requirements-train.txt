# Packages needed to TRAIN on the GPU machine.

# This is a subset of requirements.txt. The preprocessing packages are left
# out, because the preprocessing is already done and its outputs are copied
# across: lingua-language-detector (language annotation), datasketch
# (near-duplicate clustering) and truststore (a macOS certificate fix).
#
# PyTorch is NOT listed here on purpose. The right build depends on the CUDA
# version installed on the machine, so a pinned version here would be wrong
# half the time. Install it first, from the command the official site gives
# for your CUDA version:
#
#     https://pytorch.org/get-started/locally/
#
# For example, CUDA 12.4:
#     pip install torch --index-url https://download.pytorch.org/whl/cu124
#
# Then check it actually sees the GPU before going further:
#     python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
#
# Then install everything below:
#     pip install -r requirements-train.txt
